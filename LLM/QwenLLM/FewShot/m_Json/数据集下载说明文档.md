## 一、项目背景

Security Datasets 是 OTRF（Open Threat Research Federation）维护的开源安全数据集项目，提供真实模拟的攻防场景日志，涵盖 Windows、Linux、AWS 等平台。数据集以 JSON 格式存储（Windows 事件日志格式），可直接用于威胁检测分析、机器学习特征工程、以及安全分析师技能训练。

**项目网站**：https://securitydatasets.com  
**GitHub 仓库**：https://github.com/OTRF/Security-Datasets

## 三、数据集筛选方法

### 3.1 元数据文件解析

每个数据集对应 `datasets/atomic/_metadata/` 下一个 YAML 文件，文件名格式为 `SDWIN-YYMMDDHHMMSS.yaml`（SDWIN 代表 Windows 平台数据集）。YAML 文件包含以下关键字段：

```yaml
title: 数据集名称
id: SDWIN-XXXXXXXXXX
platform: [Windows]
tags:
  - 攻击技术标签
attack_mappings:
  - technique: T1055        # MITRE ATT&CK 技术 ID
    tactics: [TA0005]       # 战术分类
files:
  - type: Host              # Host = 主机日志（JSON），Network = 网络包（pcap）
    link: https://raw.githubusercontent.com/OTRF/Security-Datasets/master/datasets/...zip
```

### 3.2 筛选关键词

使用 `grep` 命令在所有 `SDWIN-*.yaml` 文件中搜索以下关键词，筛选出与 Windows 主机安全相关的数据集：

```bash
# 搜索注入/Hook 相关
grep -li "inject\|hook\|process inject\|dll inject" SDWIN*.yaml

# 搜索命令行执行相关
grep -li "command line\|cmd\|powershell\|execution" SDWIN*.yaml

# 搜索凭据/进程内存相关
grep -li "lsass\|credential\|mimikatz\|dump" SDWIN*.yaml
```

### 3.3 筛选结果

共筛选出 **62 个**符合条件的 Windows 主机安全数据集，覆盖 5 大攻击类别（见第四节）。

## 五、提取操作步骤详解

### 5.1 发现数据集存储方式

首先确认本地已有 zip 格式的数据包：

```bash
ls datasets/atomic/windows/defense_evasion/host/
# 输出: empire_psinject_PEinjection.zip, empire_dllinjection_*.zip ...

# 查看 zip 内容确认文件格式
unzip -l datasets/atomic/windows/defense_evasion/host/empire_psinject_PEinjection.zip
# 输出: empire_psinject_PEinjection_2020-08-07143205.json（单个大 JSON 文件）
```

每个 zip 包含一个 `.json` 文件，该 JSON 是 Windows 事件日志的 NDJSON（换行符分隔的 JSON）格式，每行一条事件记录。

### 5.2 创建目录结构

```bash
BASE=m_Json
mkdir -p "$BASE/01_process_injection"
mkdir -p "$BASE/02_credential_access"
mkdir -p "$BASE/03_privilege_escalation"
mkdir -p "$BASE/04_defense_evasion_lolbins"
mkdir -p "$BASE/05_log_tampering"
```

### 5.3 批量解压 JSON 文件

使用 `unzip -jo` 参数解压（`-j` 去除目录层级，`-o` 覆盖已有文件）：

```bash
# 示例：解压进程注入类数据集
SRC=datasets/atomic/windows/defense_evasion/host
DST=m_Json/01_process_injection

unzip -jo "$SRC/empire_psinject_PEinjection.zip" "*.json" -d "$DST"
unzip -jo "$SRC/empire_dllinjection_LoadLibrary_CreateRemoteThread.zip" "*.json" -d "$DST"
unzip -jo "$SRC/psh_mavinject_dll_notepad.zip" "*.json" -d "$DST"
# ... 以此类推
```

### 5.4 清理 macOS 元数据文件

macOS 系统在解压时可能产生 `._` 开头的元数据文件，需清理：

```bash
find m_Json -name "._*" -delete
```

## 七、数据集 JSON 格式说明

每个 JSON 文件是 NDJSON 格式（每行一条记录），每条记录对应一个 Windows 事件日志条目，关键字段包括：

```json
{
  "EventID": 4688,                          // 事件 ID（如 4688=进程创建）
  "Channel": "Security",                    // 日志通道
  "CommandLine": "mimikatz.exe sekurlsa::logonpasswords",  // 命令行参数
  "ParentProcessName": "C:\\Windows\\System32\\cmd.exe",   // 父进程路径
  "NewProcessName": "C:\\Users\\...\\mimikatz.exe",        // 新进程路径
  "SubjectUserName": "pgustavo",            // 执行用户
  "TimeCreated": "2020-08-07T14:32:05Z"    // 时间戳
}
```

**常见高价值事件 ID**：

| EventID | 说明 | 相关检测场景 |
|---------|------|------------|
| 4688 | 进程创建（含命令行） | 危险进程名、异常命令行 |
| 10 (Sysmon) | 进程访问 | LSASS 内存读取 |
| 8 (Sysmon) | CreateRemoteThread | DLL 注入、代码注入 |
| 7 (Sysmon) | 镜像加载 | 可疑 DLL 加载 |
| 4663 | 对象访问 | SAM 数据库访问 |
| 4624/4625 | 登录成功/失败 | 凭据攻击 |
